## Context

见 proposal.md。当前 argparse CLI 有十二个子命令，无展示依赖；安装脚本复制源码，CLI 内包含切换和编辑编排，存储/恢复已独立。主规格尚未归档，历史产物不修改。

## Goals / Non-Goals

**Goals:** CLI 与 TUI 共享命令目录、校验及操作服务；隔离安装默认提供完整界面。

**Non-Goals:** 不改变代理存储格式、Codex 二进制更新策略或诊断分类含义，不在真实服务上验收。

## Decisions

- 使用 Textual 8.2.8–8.x、Rich 14.2+；CSS 作为包资源。深灰底、蓝绿强调、橙红异常。四个标签页，100 列以上代理列表和详情左右排列，小屏上下滚动。
- 将操作编排放入服务，CLI 的编辑器路径保持原样，TUI 使用隐藏 URL 表单。阶段回调只报告真正完成的步骤，回滚错误保留原错误信息。
- 后台线程执行阻塞操作，主线程收消息更新界面。应用层 busy 门禁避免取消旧线程后启动新事务；操作期间阻止正常退出。检查结果绑定配置，修改后标记过期。
- 命令目录保存双语说明、参数、示例；Rich 渲染 CLI，Textual 表格及详情复用目录。JSON 路径不装饰。无参数非终端显示帮助返回 0；显式 tui 无终端返回 2。
- 全局 --lang 可在子命令两侧；显式参数 > CODEX_SOCKS_LANG > LC_ALL/LC_MESSAGES/LANG，zh 前缀映射简中，其余英文。界面语言仅会话内保存。
- 版本化私有 venv 保留绝对路径，避免移动环境导致 shebang 失效；依赖及导入检查、Codex 发现成功才更新命令入口。已有配置保持 XDG 路径，旧环境保留以支持保存的 launcher。
- CLI 与 TUI 表格显示脱敏 URL，用户内容作为字面文本，禁止将凭据写入通知或错误展示。示例/截图仅使用保留域名。

## Risks / Trade-offs

- app-server 重启可能中断调用会话 → 确认提示及模拟测试，不执行生产重启。
- 第三方包安装需要网络或本地缓存 → 提前安装到新环境，失败不替换旧入口；缺少 venv 时给出诊断。
- 历史快照可能引用旧解释器 → 保留旧环境，不自动清理。
- 窄终端和中文字符宽度 → 80×24 与 120×36 双语 Pilot 测试，检查实际渲染截图。

## Migration Plan

更新依赖声明、安装器和双语文档，原 shell 安装用户重新运行安装脚本即可迁移；测试使用临时 HOME/XDG 与 fake Codex。完整测试、shellcheck、secrets 和严格 OpenSpec 校验后交付。
